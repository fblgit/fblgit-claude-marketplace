# Security policy

## Supported versions

Only the current `main` branch is supported. Fixes are made against it.

## Scope

This policy covers the plugins whose source is in this repository: `artifact-data-protocol` and `adp-setup`. The other plugins in the
marketplace are listed here and live in their own repositories; report a problem in one of them there.

## Reporting a vulnerability

Report privately with GitHub private vulnerability reporting: open the
repository's **Security** tab, choose **Report a vulnerability**, and fill in
the form. Please do not open a public issue or pull request for a
vulnerability.

Include what you found, the plugin and commit, and steps to reproduce.

If you find a secret committed to the repository, report it the same way.
