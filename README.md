# fblgit-claude-marketplace

A marketplace of Claude Code plugins and mods.

## Add it

```
/plugin marketplace add fblgit/fblgit-claude-marketplace
```

## Plugins

| Plugin | Version | What it is |
| :- | :- | :- |
| mod-authoring | 0.2.0 | skill: build, test, secure and audit Claude Code mods |
| artifacts-done-properly | tracks `main` | skills, page templates and a component catalog for reusable claude.ai Artifacts ([repo](https://github.com/fblgit/artifacts-done-properly)) |

Install one: `/plugin install mod-authoring@fblgit-claude-marketplace`, or `/plugin install artifacts-done-properly@fblgit-claude-marketplace`
